# 실습과제 1
  
**1. 16MB 메모리의 주소 범위를 구하시오.**
  
16MB = 16 × 1,024 × 1,024바이트
= 16,777,216바이트
= 2²⁴바이트
  
주소의 범위는 다음과 같다.
  
* 10진수: 0 ~ 16,777,215
  
주소가 0부터 시작하기 때문에 마지막 주소는 전체 메모리 크기에서 1을 뺀 16,777,215가 된다.

 &nbsp;
  
**2. 변수의 주소를 설명하시오.**
  
변수의 주소란 해당 변수의 값이 저장되어 있는 메모리 공간의 위치를 의미한다. 주소 연산자 &를 사용하여 변수의 주소를 구할 수 있다.

 &nbsp;
  
**3. 변수 주소의 자료형은 무엇인가?**
  
변수 주소의 자료형은 해당 변수 자료형의 포인터형이다.

* char형 변수 a의 주소인 &a의 자료형은 char *이다.
* int형 변수 b의 주소인 &b의 자료형은 int *이다.
* double형 변수 c의 주소인 &c의 자료형은 double *이다.

&nbsp;
  
**4. 포인터란 무엇인가?**
  
포인터란 다른 변수의 메모리 주소를 저장하는 변수이다.

 &nbsp;
  
**5. 포인터의 자료형은 무엇인가?**
  
포인터의 자료형은 포인터가 가리키는 변수의 자료형에 따라 결정된다.
  
```
char *pa;
int *pb;
double *pc;
```
  
* char *는 char형 변수를 가리키는 포인터 자료형이다.
* int *는 int형 변수를 가리키는 포인터 자료형이다.
* double *는 double형 변수를 가리키는 포인터 자료형이다.

 &nbsp;
  
**6. 변수의 주소를 int형 변수에 저장하면 어떻게 되는가?**
  
변수의 주소는 포인터형이므로 일반적인 int형 변수에 직접 저장하면 안 된다.

 &nbsp;

# 실습과제 2

**1. pt가 가리키는 데이터의 자료형은 무엇인가?**

포인터 변수 pt가 가리키는 데이터의 자료형은 double형이다.

 &nbsp;


**2. pt에 저장될 주소의 자료형은 무엇인가?**

pt에는 double형 변수의 주소가 저장되어야 한다. double형 변수의 주소는 double *형이다.

 &nbsp;

**3. pt의 자료형은 무엇인가?**

pt의 자료형은 double형 포인터 double *형이다.

 &nbsp;

**4. 포인터를 선언할 때 double의 의미를 설명하시오.**

다음 선언에서 double은 포인터 변수 pt가 가리키는 데이터의 자료형을 의미한다.

pt에는 double형 변수의 주소를 저장해야 하며, pt가 가리키는 메모리의 데이터를 double형으로 해석해야 한다.

 &nbsp;

**5. 포인터 변수 pt가 메모리에 할당될 때 메모리 크기는 얼마인가?**

포인터 변수 pt에 할당되는 메모리 크기는 컴퓨터의 실행 환경에 따라 달라진다.

* 32비트 환경: 일반적으로 4바이트
* 64비트 환경: 일반적으로 8바이트

pt가 가리키는 double형 데이터의 크기는 일반적으로 8바이트이지만, 포인터 변수 pt 자체의 크기는 double형의 크기와 관계없이 메모리 주소를 저장하는 데 필요한 크기로 결정된다.

 &nbsp;

# 실습과제 4
## 소스코드 설명

```
#include <stdio.h>
```

* printf 등 라이브러리 객체의 선언을 포함하고 있는 헤더파일 stdio.h를 포함하라

```
int main(void)
```

* 메인함수 시작

```
char a = 'A';
```

* char형 변수 a의 'A'라는 문자 대입

```
int b = 36;
```

* int형 변수 b의 36 대입

```
double c = 3.141592;
```

* double형 변수 c의 3.141592 대입

```
printf("char형 변수 a의 주소: %u \n", &a);
printf("int형 변수 b의 주소: %u \n", &b);
printf("double형 변수 c의 주소 : %u \n", &c);
```

* printf 함수를 이용하여 변수 a,b,c의 주소 출력, %u는 부호없는 정수를 출력하는 서식 문자이고 &a, %b, %c의 %(앰퍼센드)는 변수의 주소를 계산하는 연산자임

```
return 0;
```

* 0을 반환하고 메인함수 정상 종료
