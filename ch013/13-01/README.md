# 실습과제 1

**1. 배열명의 의미를 설명하라.**

배열명은 선언한 배열을 나타내는 이름이다. 식에서 사용하면 대부분 배열의 첫 번째 요소를 가리키는 포인터로 변환된다.

```c
int a[3] = { 5, 15, 25 };
int* p = a;
```

* `p = a`는 `p = &a[0]`과 같이 배열의 첫 번째 요소 주소를 저장한다.
* 이때 `a`에서 변환된 포인터의 자료형은 `int*`이고, 가리키는 요소의 자료형은 `int`이다.
* 배열명은 포인터 변수처럼 저장된 주소를 바꿀 수 없으므로 `a = p`, `a++` 같은 연산은 할 수 없다.
* 배열 자체의 자료형은 `int[3]`이다. `sizeof(a)`에서는 포인터로 변환되지 않고 배열 전체의 크기를 구한다.

&nbsp;

**2. 배열표현과 포인터(주소) 표현의 변환 공식을 설명하라.**

|구분|배열 표현|포인터(주소) 표현|
|------|---|---|
|요소의 값|`a[i]`|`*(a + i)`|
|요소의 주소|`&a[i]`|`a + i`|

`a + i`는 인덱스가 `i`인 요소의 주소이고, 여기에 간접참조 연산자 `*`를 사용하면 그 요소에 저장된 값을 읽거나 변경할 수 있다.

&nbsp;

**3. 배열의 첫 번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있다. 방법을 설명하시오.**

배열의 요소들은 같은 자료형으로 메모리에 연속해서 저장된다. 첫 번째 요소를 가리키는 포인터가 `p`라면 인덱스가 `i`인 요소의 주소는 `p + i`로 구한다.

```text
각 요소의 주소 = 첫 번째 요소의 주소 + i × 요소 한 개의 크기
```

예를 들어 요소의 크기가 4바이트이고 첫 번째 요소의 주소가 2000이라면, 인덱스가 2인 요소의 주소는 2000 + 2 × 4 = 2008이다.

주소를 올바르게 계산하려면 요소의 자료형을 알아야 하고, 접근할 수 있는 범위는 배열의 길이로 확인해야 한다.

&nbsp;

**4. 배열의 첫 번째 요소의 주소만 알면 모든 원소의 값을 계산할 수 있다. 방법을 설명하시오.**

각 요소의 주소를 구한 다음 간접참조 연산자 `*`를 사용하여 그 위치에 저장된 값을 읽는다.

```c
int a[3] = { 5, 15, 25 };
int* p = a;
```

* `*p`는 첫 번째 요소에 저장된 5이다.
* `*(p + 1)`은 두 번째 요소에 저장된 15이다.
* `*(p + 2)`는 세 번째 요소에 저장된 25이다.

값을 주소만으로 만들어 내는 것이 아니라, 계산한 주소에서 이미 저장된 값을 읽는 것이다. 따라서 초기화된 요소에 배열 범위 안에서 접근해야 한다.

&nbsp;

**5. 포인터에 대해 가능한 연산의 종류와 의미를 설명하라.**

|연산|의미|
|------|---|
|`*p`|p가 가리키는 객체에 접근한다.|
|`p + n`|n개의 요소만큼 뒤에 있는 주소를 구한다.|
|`p - n`|n개의 요소만큼 앞에 있는 주소를 구한다.|
|`p++`, `++p`|p를 다음 요소의 주소로 변경한다.|
|`p--`, `--p`|p를 이전 요소의 주소로 변경한다.|

* 포인터에 정수를 더하거나 뺄 때는 해당 정수에 `sizeof(*p)`를 곱한 바이트 수만큼 이동한다.
* 같은 배열 안의 두 요소를 가리키는 포인터는 서로 빼서 요소 사이의 간격을 구하거나 대소를 비교할 수 있다. 포인터끼리 더하거나 곱하는 연산은 할 수 없다.
* 배열의 마지막 요소 바로 다음 주소까지 계산할 수 있지만, 그 주소를 간접참조하여 값을 읽거나 쓰면 안 된다.

&nbsp;

**6. 포인터 연산을 기존의 산술연산과 다르게 정의한 이유는 무엇일까?**

포인터는 특정 자료형의 객체를 가리키므로, 다음 요소로 이동할 때 그 자료형의 크기를 고려해야 하기 때문이다.

`double`이 8바이트인 환경에서는 다음 `double` 요소가 8바이트 뒤에 있다. 포인터를 1 증가시킬 때 1바이트만 이동한다면 다음 요소의 시작 위치를 가리킬 수 없다.

포인터 연산이 요소의 크기를 자동으로 반영하면 자료형마다 바이트 수를 직접 계산하지 않고도 `p + 1`로 다음 요소를 가리킬 수 있다.

# 실습과제 2

## 소스코드 설명

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
```

* Visual Studio에서 `scanf` 사용에 대한 보안 경고를 해제한다.
* `printf`, `scanf`의 선언이 들어 있는 stdio.h를 포함한다.

```c
int main(void)
```

* 메인함수 시작

```c
int grade[5];
int sum = 0, i, average;
```

* 성적 5개를 저장할 int형 배열 grade를 선언한다.
* 합계를 저장할 sum을 0으로 초기화하고, 반복에 사용할 i와 평균을 저장할 average를 선언한다.

```c
for (i = 0; i < 5; i++)
{
    printf("성적을 입력하시오: ");
    if (scanf("%d", grade + i) != 1)
        return 1;
}
```

* 배열 표현인 `&grade[i]`를 주소 표현인 `grade + i`로 바꾸어 입력받은 정수를 저장한다.
* `grade + i` 자체가 주소이므로 앞에 `&`를 붙이지 않는다.
* 정수 입력에 실패하면 1을 반환하고 종료한다.

```c
for (i = 0; i < 5; i++)
    sum += *(grade + i);
```

* 배열 표현인 `grade[i]`를 포인터 표현인 `*(grade + i)`로 바꾸어 성적의 합을 구한다.

```c
average = (int)(sum / 5.0);
printf("성적 평균= %d\n", average);
```

* 합계를 5.0으로 나눈 뒤 int형으로 변환하여 average에 저장하고 출력한다.
* 문제에 주어진 average의 int형을 유지했으므로 소수 부분은 버려진다. `(int)`는 원래 코드에서 자동으로 이루어지던 변환을 명시한 것이다.

```c
return 0;
```

* 0을 반환하고 메인함수 정상 종료

# 실습과제 3

**1. 증감연산자 a++, ++a의 차이를 설명하시오.**

두 연산 모두 a의 값을 1 증가시키지만, 식에서 사용하는 값이 다르다.

```c
int a = 7;
int b = a++;
```

* `a++`는 증가 전의 값을 식의 값으로 사용한다. 실행 후 b는 7, a는 8이다.

```c
int a = 7;
int b = ++a;
```

* `++a`는 증가한 값을 식의 값으로 사용한다. 실행 후 a와 b는 모두 8이다.
* 다른 식에 사용하지 않고 `a++;` 또는 `++a;`만 실행하면 두 경우 모두 a가 1 증가한다.

&nbsp;

**2. 다음 코드의 문제점을 설명하고 포인터를 이용하여 문제를 해결하시오.**

```c
sum += *a++;
```

* 후위 증가 연산자가 간접참조 연산자보다 우선하므로 `sum += *(a++);`로 해석된다.
* 문제의 a는 배열명이므로 `a++`로 변경할 수 없어 컴파일 오류가 발생한다.
* 배열의 첫 번째 요소를 가리키는 포인터 변수 p를 선언하고, a 대신 p를 증가시키면 된다.

## 소스코드 설명

```c
int a[] = { 10, 20, 30 };
int* p = a;
int i, sum = 0;
```

* 배열 a를 10, 20, 30으로 초기화한다.
* int형 포인터 변수 p에 a의 첫 번째 요소 주소를 저장하고, 합계를 저장할 sum을 0으로 초기화한다.

```c
for (i = 0; i < 3; i++)
    sum += *p++;
```

* `*p++`는 `*(p++)`와 같다. 증가 전 p가 가리키던 요소의 값을 더하고 p는 다음 요소를 가리키게 된다.
* 10, 20, 30을 순서대로 더하므로 sum은 60이 된다.
* 세 번째 반복 후 p는 마지막 요소 바로 다음을 가리키지만, 이후에는 간접참조하지 않는다.

```c
printf("sum:%d\n", sum);
return 0;
```

* 합계를 출력하고 메인함수 정상 종료

# 실습과제 4

## 문제

실수 5개를 키보드로 입력받아 배열에 저장하고, 각 요소의 값에 2를 더한 결과를 출력한다. 입력과 값 변경에는 포인터 변수를 증가시키는 연산을 사용한다.

## 소스코드 설명

```c
double a[5];
double* p = a;
int i;
```

* 실수 5개를 저장할 double형 배열 a를 선언한다.
* double형 포인터 변수 p가 배열의 첫 번째 요소를 가리키도록 초기화한다.

```c
for (i = 0; i < 5; i++)
{
    printf("%d번째 실수 입력: ", i + 1);
    if (scanf("%lf", p++) != 1)
        return 1;
}
```

* double형 실수를 입력받기 위해 `%lf`를 사용한다.
* `p++`는 증가 전의 주소를 scanf에 전달하고 p를 다음 요소의 주소로 변경한다.
* 입력에 실패하면 종료하므로 값이 저장되지 않은 요소를 사용하지 않는다.

```c
p = a;
for (i = 0; i < 5; i++)
{
    *p += 2.0;
    p++;
}
```

* 입력을 마친 p를 배열의 첫 번째 요소로 되돌린다.
* p가 가리키는 실수에 2.0을 더한 다음 p를 증가시켜 다음 요소로 이동한다.
* `*p += 2.0`은 배열에 저장된 값을 바꾸고, `p++`는 포인터가 가리키는 위치를 바꾼다.

```c
p = a;
printf("각 원소에 2를 더한 값:");
for (i = 0; i < 5; i++)
    printf(" %.2f", *p++);
printf("\n");
```

* 출력 전에 p를 다시 첫 번째 요소로 되돌린다.
* 각 요소를 소수점 이하 두 자리까지 출력하고 다음 요소로 이동한다.

# 실습과제 5

## 문제

실수 5개를 키보드로 입력받아 배열에 저장하고, 포인터 덧셈연산을 이용하여 각 요소의 값에 2를 더한다. 변경한 배열을 예제 11의 다섯 가지 표현으로 출력한다.

## 소스코드 설명

```c
#define _CRT_SECURE_NO_WARNINGS
#pragma warning(disable:6031)
#include <stdio.h>
```

* Visual Studio에서 scanf의 보안 경고와 반환값을 확인하지 않을 때 발생하는 분석 경고 C6031을 해제한다. 이 코드에서는 입력 성공 여부도 직접 확인한다.
* printf와 scanf의 선언이 들어 있는 stdio.h를 포함한다.

```c
double arr[5];
double* ptr = arr;
double* temp;
int i;
```

* double형 배열 arr에 실수 5개를 저장하고, ptr에 첫 번째 요소의 주소를 저장한다.
* temp는 다섯 번째 출력 방식에서 증가시킬 포인터 변수이다.

```c
printf("5개의 실수를 입력하시오.\n");
for (i = 0; i < 5; i++)
{
    if (scanf("%lf", ptr + i) != 1)
        return 1;
}
```

* `ptr + i`로 입력할 요소의 주소를 구한다. ptr 자체는 바뀌지 않는다.
* double형 실수를 입력받기 위해 `%lf`를 사용하며, 입력에 실패하면 종료한다.

```c
for (i = 0; i < 5; i++)
    *(ptr + i) += 2.0;
```

* 각 요소의 주소를 간접참조하여 저장된 값에 2.0을 한 번씩 더한다.
* 이후 다섯 가지 출력에서는 값을 추가로 변경하지 않으므로 같은 결과가 다섯 줄 출력된다.

&nbsp;

**1. 배열명을 이용한 배열 표현**

```c
printf("1. arr[i] : ");
for (i = 0; i < 5; i++)
    printf("%.2f ", arr[i]);
printf("\n");
```

* 배열명 arr에 인덱스를 붙여 각 요소의 값을 출력한다.

&nbsp;

**2. 배열명을 이용한 주소 표현**

```c
printf("2. *(arr + i) : ");
for (i = 0; i < 5; i++)
    printf("%.2f ", *(arr + i));
printf("\n");
```

* `arr + i`로 요소의 주소를 구하고, 간접참조 연산자 `*`로 값을 읽어 출력한다.

&nbsp;

**3. 포인터 변수를 이용한 배열 표현**

```c
printf("3. ptr[i] : ");
for (i = 0; i < 5; i++)
    printf("%.2f ", ptr[i]);
printf("\n");
```

* 포인터 변수도 인덱스와 함께 사용할 수 있다. ptr이 arr의 첫 번째 요소를 가리키므로 `ptr[i]`는 `arr[i]`와 같은 요소이다.

&nbsp;

**4. 포인터 변수를 이용한 주소 표현**

```c
printf("4. *(ptr + i) : ");
for (i = 0; i < 5; i++)
    printf("%.2f ", *(ptr + i));
printf("\n");
```

* `ptr + i`가 가리키는 요소를 간접참조하여 출력한다. ptr은 계속 첫 번째 요소를 가리킨다.

&nbsp;

**5. 증감연산자를 이용한 주소 표현**

```c
temp = ptr;
printf("5. *temp++ : ");
for (i = 0; i < 5; i++)
    printf("%.2f ", *temp++);
printf("\n");
```

* `temp = ptr`로 첫 번째 요소의 주소를 복사한다. `*temp++`는 `*(temp++)`로 해석되어 증가 전 temp가 가리키던 값을 출력하고 temp는 다음 요소로 이동한다. ptr은 변경되지 않는다.

&nbsp;

```c
return 0;
```

* 0을 반환하고 메인함수 정상 종료
