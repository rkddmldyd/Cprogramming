# 실습과제 1

**1. C언어에서 문자를 메모리에 저장하는 방식에 대하여 설명하라.**

C언어에서는 문자 자체를 메모리에 저장하는 것이 아니라, 문자에 대응하는 정수 형태의 문자 코드를 저장한다. 영문자와 숫자, 기호는 일반적으로 아스키 코드로 표현한다.

|문자|아스키 코드값|
|------|---:|
|`'A'`|65|
|`'Z'`|90|
|`'a'`|97|
|`'z'`|122|

```c
char ch = 'A';
```

* 위 코드에서 메모리에는 `'A'`에 해당하는 아스키 코드값 65가 저장된다.
* `char`형 변수는 문자 코드 하나를 저장하며, 크기는 1바이트이다.
* 문자열은 `char`형 배열에 각 문자의 코드값이 차례대로 저장되고, 마지막에는 문자열의 끝을 나타내는 널문자 `\0`이 저장된다.

예를 들어 `char str[] = "ABC";`는 메모리에 다음과 같이 저장된다.

|배열 요소|저장 문자|아스키 코드값|
|------|---|---:|
|`str[0]`|`'A'`|65|
|`str[1]`|`'B'`|66|
|`str[2]`|`'C'`|67|
|`str[3]`|`'\0'`|0|

&nbsp;

**2. 널문자의 용도를 설명하라.**

널문자 `\0`은 아스키 코드값이 0인 문자이며 C언어에서 문자열의 끝을 표시한다.

```c
char str[] = "Hello";
```

위 문자열은 메모리에 `'H'`, `'e'`, `'l'`, `'l'`, `'o'`, `'\0'`의 순서로 저장된다. 실제 문자는 5개이지만 널문자까지 포함하므로 배열에는 6개의 요소가 필요하다. `printf`에서 `%s`로 문자열을 출력할 때도 널문자를 만날 때까지 문자를 차례대로 출력한다.

&nbsp;

**3. 메모리에 저장된 문자열의 끝을 찾는 방법을 설명하라.**

문자열의 첫 번째 요소부터 한 문자씩 검사하여 널문자 `\0`이 저장된 위치를 찾는다.

```c
int i = 0;

while (str[i] != '\0')
{
    i++;
}
```

* 현재 문자가 널문자가 아니면 `i`를 증가시켜 다음 문자를 검사한다.
* 반복이 끝났을 때 `str[i]`가 널문자이므로 `i`는 문자열이 끝나는 위치를 나타낸다.
* 배열의 범위를 벗어나기 전에 널문자를 만날 수 있도록 문자열을 올바르게 저장해야 한다.

&nbsp;

**4. 문자열의 길이를 구하는 알고리즘을 설명하라.**

문자열의 길이는 첫 번째 문자부터 널문자를 만나기 전까지의 문자 수이다.

1. 길이를 저장할 변수 `i`를 0으로 초기화한다.
2. `str[i]`가 널문자인지 확인한다.
3. 널문자가 아니면 `i`를 1 증가시킨다.
4. 널문자를 만날 때까지 2~3번을 반복한다.
5. 반복이 끝난 시점의 `i`가 널문자를 제외한 문자열의 길이이다.

예를 들어 `"Hello"`는 다섯 문자를 검사한 다음 널문자를 만나므로 길이는 5이다.

# 실습과제 2

## 문제

키보드로 문자열을 입력받고, 문자열의 각 문자를 실행 결과와 같이 출력한다. 문자열의 끝은 널문자 `\0`을 이용하여 판단한다.

## 소스코드 설명

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
```

* Visual Studio에서 `scanf` 사용에 대한 보안 경고를 해제한다.
* `printf`, `scanf`의 선언이 들어 있는 stdio.h를 포함한다.

```c
char str[100];
int i = 0;
```

* 최대 99개의 문자와 마지막 널문자를 저장할 `char`형 배열 str을 선언한다.
* 배열의 인덱스로 사용할 i를 0으로 초기화한다.

```c
printf("문자열을 입력하시오: ");
if (scanf("%99s", str) != 1)
    return 1;
```

* 문자열을 입력받아 str에 저장한다. `%99s`를 사용하여 배열의 크기를 넘지 않도록 입력 문자 수를 제한한다.
* 문자열 입력에 실패하면 1을 반환하고 프로그램을 종료한다.

```c
while (str[i] != '\0')
{
    printf("%d번째문자 %c\n", i + 1, str[i]);
    i++;
}
```

* 현재 문자가 널문자가 아닌 동안 반복한다.
* `str[i]`를 한 문자씩 출력한 후 i를 증가시켜 다음 문자로 이동한다.
* 배열 인덱스는 0부터 시작하므로 화면에는 `i + 1`을 출력하여 첫 번째 문자부터 표시한다.

```c
return 0;
```

* 0을 반환하고 메인함수 정상 종료

# 실습과제 3

## 문제

키보드로 문자열을 입력받아 대문자는 소문자로, 소문자는 대문자로 변환한다. 라이브러리 함수는 사용하지 않고 아스키 코드의 규칙을 이용한다.

## 소스코드 설명

```c
char str[100];
int i = 0;
```

* 입력 문자열을 저장할 배열 str과 문자를 차례로 검사할 인덱스 i를 선언한다.

```c
printf("문자열을 입력하시오: ");
if (scanf("%99s", str) != 1)
    return 1;
```

* 키보드로 입력한 문자열을 str에 저장한다.
* 입력에 실패하면 1을 반환하고 종료한다.

```c
while (str[i] != '\0')
{
    if (str[i] >= 'A' && str[i] <= 'Z')
        str[i] = str[i] + ('a' - 'A');
    else if (str[i] >= 'a' && str[i] <= 'z')
        str[i] = str[i] - ('a' - 'A');

    i++;
}
```

* 널문자를 만날 때까지 각 문자를 검사한다.
* 대문자 범위의 문자는 대문자와 소문자의 코드값 차이를 더하여 소문자로 바꾼다.
* 소문자 범위의 문자는 같은 차이를 빼서 대문자로 바꾼다.
* 숫자나 기호처럼 영문자가 아닌 문자는 변경하지 않는다.

```c
printf("변환결과: %s\n", str);
return 0;
```

* 변환한 문자열을 출력하고 메인함수를 정상 종료한다.

# 실행결과

```text
문자열을 입력하시오: HelloWorld
변환결과: hELLOwORLD
```

# 실습과제 4

## 문제

소문자로 이루어진 문자열 두 개를 입력받고 각 문자열의 첫 번째 문자 아스키 코드값을 비교하여 사전에서 앞에 나오는 문자열을 출력한다.

## 소스코드 설명

```c
char str1[100];
char str2[100];
```

* 두 문자열을 저장할 char형 배열 str1과 str2를 선언한다.

```c
printf("문자열을 입력하시오: ");
if (scanf("%99s", str1) != 1)
    return 1;

printf("문자열을 입력하시오: ");
if (scanf("%99s", str2) != 1)
    return 1;
```

* 두 문자열을 차례대로 입력받는다.
* 각 입력의 길이를 최대 99자로 제한하고, 입력에 실패하면 프로그램을 종료한다.

```c
if (str1[0] < str2[0])
    printf("사전에서 앞에 나오는 문자열: %s\n", str1);
else if (str1[0] > str2[0])
    printf("사전에서 앞에 나오는 문자열: %s\n", str2);
else
    printf("두 문자열의 첫 번째 문자가 같습니다.\n");
```

* 소문자 아스키 코드값은 알파벳 순서대로 증가하므로 첫 번째 문자의 코드값이 작은 문자열이 사전에서 앞에 나온다.
* 첫 번째 문자가 같으면 첫 문자만으로는 순서를 정할 수 있으므로 같다는 메시지를 출력한다.
* 이 코드는 문제의 조건에 따라 첫 번째 문자만 비교한다.

```c
return 0;
```

* 0을 반환하고 메인함수 정상 종료

# 실행결과

```text
문자열을 입력하시오: hello
문자열을 입력하시오: world
사전에서 앞에 나오는 문자열: hello
```

# 실습과제 5

## 문제

문자열 배열 `fruits`에서 사전상 가장 앞에 나오는 문자열을 찾는다. 라이브러리 함수를 사용하지 않고 각 문자열의 첫 번째 문자 중 가장 작은 아스키 코드값을 찾는다.

## 소스코드 설명

```c
const char* fruits[] = { "apple", "blueberry", "orange", "melon" };
int i;
int min = 0;
int count = sizeof(fruits) / sizeof(fruits[0]);
```

* 네 개의 문자열을 가리키는 포인터 배열 fruits를 선언한다.
* 문자열 리터럴을 변경하지 않으므로 포인터가 가리키는 문자의 자료형에 const를 사용한다.
* min에는 현재까지 가장 앞에 나오는 문자열의 인덱스를 저장한다. 처음에는 첫 번째 문자열을 기준으로 삼기 위해 0으로 초기화한다.
* 배열 전체 크기를 요소 하나의 크기로 나누어 문자열의 개수 count를 구한다.

```c
for (i = 1; i < count; i++)
{
    if (fruits[i][0] < fruits[min][0])
        min = i;
}
```

* 두 번째 문자열부터 마지막 문자열까지 차례로 검사한다.
* `fruits[i][0]`은 i번째 문자열의 첫 번째 문자이다.
* 현재 문자열의 첫 번째 문자 코드값이 기준 문자열보다 작으면 min을 현재 인덱스로 변경한다.

```c
printf("사전에서 가장 앞에 나오는 문자열: %s\n", fruits[min]);
return 0;
```

* 반복이 끝나면 min이 가리키는 문자열을 출력하고 메인함수를 정상 종료한다.

# 실행결과

```text
사전에서 가장 앞에 나오는 문자열: apple
```
