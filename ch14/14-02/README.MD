# 실습과제 1

**1. 주소에 의한 호출을 사용해야 하는 3가지 경우를 설명하라.**

* 다른 함수에 선언된 지역 변수의 원본 값을 변경할 때 사용한다. 변수의 주소를 전달하고 포인터로 간접참조하면 호출한 함수의 변수를 직접 변경할 수 있다.
* 배열을 함수에 전달할 때 사용한다. 배열 전체를 복사하는 대신 첫 번째 요소의 주소를 전달하고, 배열의 길이도 함께 전달하여 각 요소에 접근한다.
* 하나의 함수에서 두 개 이상의 계산 결과를 전달할 때 사용한다. 결과를 저장할 변수들의 주소를 매개변수로 받아 각 변수에 결과를 저장한다.

```c
split_number(number, &integer_part, &fractional_part);
```

* 정수부와 소수부를 저장할 두 변수의 주소를 전달하면 하나의 함수에서 두 결과를 main 함수에 전달할 수 있다.
* C에서는 주소도 값으로 복사하여 전달한다. 수업에서 말하는 주소에 의한 호출은 복사된 주소를 통해 원본 객체에 접근하는 방식이다.

&nbsp;

**2. 최댓값을 구하는 알고리즘을 설명하라.**

1. 배열의 첫 번째 요소를 현재 최댓값으로 저장한다.
2. 두 번째 요소부터 마지막 요소까지 차례대로 검사한다.
3. 검사 중인 값이 현재 최댓값보다 크면 최댓값을 그 값으로 변경한다.
4. 모든 요소를 검사한 뒤 저장된 값이 배열 전체의 최댓값이다.

예를 들어 50, 20, 30, 40, 10을 검사하면 첫 번째 값인 50보다 큰 값이 없으므로 최댓값은 50이다.

처음부터 최댓값을 0으로 정하면 모든 값이 음수인 배열에서 잘못된 결과가 나올 수 있다. 따라서 요소가 하나 이상인 배열의 첫 번째 값으로 초기화한다.

&nbsp;

**3. const 선언을 사용하는 이유를 설명하시오.**

const는 변경하면 안 되는 대상을 선언에 표시하여 실수로 값을 바꾸는 것을 막기 위해 사용한다. 컴파일러가 허용되지 않는 대입을 찾아낼 수 있고, 코드를 읽는 사람도 어떤 값이 유지되어야 하는지 알 수 있다.

```c
int get_max(const int* array, int n);
```

* get_max는 배열의 값을 읽어 최댓값을 구할 뿐 배열을 변경할 필요가 없다.
* 매개변수에 `const int*`를 사용하면 함수 안에서 array를 통해 배열 요소를 변경하는 실수를 막을 수 있다.
* const가 붙어도 원래 배열 자체가 무조건 상수가 되는 것은 아니다. 원래 배열이 변경 가능한 배열이면 호출한 쪽에서는 값을 바꿀 수 있다.

|선언|포인터에 저장된 주소 변경|해당 포인터를 통한 값 변경|
|------|---|---|
|`const int* p`|가능|불가능|
|`int* const p`|불가능|가능|
|`const int* const p`|불가능|불가능|

# 실습과제 2

## 문제

정수 5개를 입력받고, 최댓값을 구하는 함수를 호출하여 결과를 출력한다.

## 소스코드 설명

```c
int get_max(const int* array, int n);
```

* 배열의 시작 주소와 요소 개수를 받아 최댓값을 int형으로 반환하는 함수 원형을 선언한다.
* 함수가 배열을 변경하지 않으므로 포인터가 가리키는 자료형에 const를 붙인다.

```c
int data[5];
int i, max;
```

* 정수 5개를 저장할 배열 data, 반복 변수 i, 최댓값을 저장할 max를 선언한다.

```c
printf("정수5개를 입력 하시오.\n");
for (i = 0; i < 5; i++)
{
    if (scanf("%d", data + i) != 1)
        return 1;
}
```

* data + i는 data[i]의 주소이다. 입력한 정수를 배열의 각 요소에 저장한다.
* 정수 입력에 실패하면 종료하여 초기화되지 않은 값을 사용하지 않는다.

```c
max = get_max(data, 5);
printf("최대값은 %d입니다.\n", max);
```

* 배열의 시작 주소와 길이 5를 get_max에 전달한다.
* 반환받은 최댓값을 저장하고 문제의 출력 형식에 맞추어 출력한다.

```c
int get_max(const int* array, int n)
{
    int i;
    int max = *array;

    for (i = 1; i < n; i++)
    {
        if (*(array + i) > max)
            max = *(array + i);
    }

    return max;
}
```

* 첫 번째 요소로 max를 초기화하고 두 번째 요소부터 비교한다.
* 더 큰 값을 발견할 때마다 max를 갱신한다. 따라서 모두 음수인 입력도 처리할 수 있다.
* 반복이 끝나면 최댓값을 반환한다. 이 함수는 요소가 하나 이상인 배열을 전달받는 것을 전제로 한다.

# 실습과제 3

## 문제

키보드에서 정수 5개를 입력받아 main 함수의 배열 data에 저장하는 get_data 함수의 선언, 호출, 정의를 작성한다.

## 소스코드 설명


```c
int get_data(int* data, int n);
```

* 배열의 시작 주소와 입력할 요소 개수를 받는 get_data 함수를 선언한다.
* 배열을 변경해야 하므로 const를 붙이지 않는다. 반환값은 입력 성공 여부를 표시한다.

```c
int i, data[5];

if (get_data(data, 5) == 0)
    return 1;
```

* main에 정수 배열을 선언하고 그 시작 주소를 get_data에 전달한다.
* get_data는 전달받은 주소를 통해 main의 배열에 직접 값을 저장한다.
* 함수가 0을 반환하면 입력 실패이므로 프로그램을 종료한다.

```c
int get_data(int* data, int n)
{
    int i;

    for (i = 0; i < n; i++)
    {
        printf("%d번째 data를 입력하시오: ", i + 1);
        if (scanf("%d", data + i) != 1)
            return 0;
    }

    return 1;
}
```

* 1번째부터 5번째까지 입력 안내를 표시하고 각 요소의 주소에 정수를 저장한다.
* 모두 입력받으면 1을 반환하고, 도중에 입력이 실패하면 0을 반환한다.
* 배열의 내용은 포인터로 저장하고, return은 성공 여부 하나를 전달한다.

```c
for (i = 0; i < 5; i++)
    printf("%d번째 data: %d\n", i + 1, data[i]);
```

* get_data 호출이 끝난 후 main의 data에 저장된 정수 5개를 출력한다.
* 화면에서 순번을 1부터 표시하기 위해 i + 1을 사용한다.

# 실습과제 4

## 문제

실수를 입력받아 정수부와 소수부를 구하는 함수를 하나 작성한다. 두 결과는 포인터 매개변수를 통해 전달하고, 화면 입력과 출력은 모두 main 함수에서 처리한다.

## 소스코드 설명

[전체 소스코드](code_03.c)

```c
void split_number(double number, int* integer_part, double* fractional_part);
```

* 분리할 실수는 double형 값으로 받는다.
* 정수부를 저장할 int형 변수의 주소와 소수부를 저장할 double형 변수의 주소를 받는다.
* 두 결과는 포인터를 통해 저장하므로 함수 자체의 반환형은 void이다.

```c
double number, fractional_part;
int integer_part;

printf("실수를 입력하시오 : ");
if (scanf("%lf", &number) != 1)
    return 1;
```

* double형 실수를 입력받을 때 %lf를 사용한다.
* 입력은 main에서 수행하고, 실패하면 종료한다.

```c
if (!isfinite(number) || number < INT_MIN || number > INT_MAX)
{
    printf("int 범위 안의 유한한 실수를 입력하시오.\n");
    return 1;
}
```

* int형으로 변환하기 전에 입력 범위를 확인한다.
* limits.h의 INT_MIN과 INT_MAX로 int형의 범위를 확인하고, math.h의 isfinite로 무한대나 NaN 입력을 제외한다.

```c
split_number(number, &integer_part, &fractional_part);
printf("정수부 : %d\n", integer_part);
printf("소수부 : %.5f\n", fractional_part);
```

* 두 결과 변수의 주소를 전달하여 함수가 main의 변수에 결과를 저장하게 한다.
* 정수부는 %d, 소수부는 예시와 같이 소수점 이하 다섯 자리로 출력한다.

```c
void split_number(double number, int* integer_part, double* fractional_part)
{
    *integer_part = (int)number;
    *fractional_part = number - *integer_part;
}
```

* int형으로 변환하면 0을 향해 소수 부분을 버린 정수부를 얻는다.
* 입력한 실수에서 정수부를 빼면 소수부가 된다.
* 3.14159는 정수부 3, 소수부 약 0.14159로 분리된다. 음수 -3.14159는 정수부 -3, 소수부 약 -0.14159로 분리된다.
* 함수 안에서는 화면 입출력을 하지 않고 계산과 결과 저장만 수행한다.

# 실습과제 5

**교재 324쪽 문제 1. ShowAllData 함수의 매개변수에 const를 선언한 이유를 설명하시오.**

```c
void ShowAllData(const int* arr, int len)
{
    int i;
    for (i = 0; i < len; i++)
        printf("%d ", arr[i]);
}
```

ShowAllData는 배열의 모든 요소를 출력하는 함수이므로 배열에 저장된 값을 변경할 필요가 없다. 작성자는 함수가 전달받은 배열을 읽기만 하고 원본 값은 변경하지 않도록 매개변수를 const int형 포인터로 선언하였다.

* `const int* arr`는 arr을 통해 가리키는 정수값을 변경할 수 없다는 뜻이다.
* `printf`에서 `arr[i]`를 읽는 것은 가능하지만, `arr[i] = 0`처럼 값을 바꾸는 문장은 허용되지 않는다.
* 함수 안에서 실수로 배열을 변경하려고 하면 컴파일러가 진단하므로 원본 데이터를 보호하는 데 도움이 된다.
* 함수를 사용하는 사람에게도 배열을 출력만 한다는 의도를 전달한다.
* arr에 저장된 주소 자체를 변경하지 못하게 하는 `int* const arr`와는 다르다. 또한 호출한 쪽의 원본 배열 자체를 const 배열로 바꾸는 것은 아니다.

이 문제는 const 선언의 목적을 설명하는 서술형 문제이므로 별도의 실행 화면은 필요하지 않다.

# 도전과제 1

## 문제

정수 10개를 main 함수에서 입력받아 배열에 저장한다. 홀수만 출력하는 함수와 짝수만 출력하는 함수를 각각 작성하고, 홀수를 먼저 출력한 뒤 짝수를 출력한다.

## 소스코드 설명

[전체 소스코드](challenge_01.c)

```c
void print_odd(const int* array, int n);
void print_even(const int* array, int n);
```

* 배열의 주소와 길이를 받는 두 함수를 선언한다.
* 출력만 수행하므로 포인터 매개변수에 const를 사용하여 배열의 값을 변경하지 않도록 한다.

```c
int data[10];
int i;

printf("총 10개의 숫자 입력\n");
for (i = 0; i < 10; i++)
{
    printf("입력: ");
    if (scanf("%d", data + i) != 1)
        return 1;
}
```

* 문제의 조건대로 main 함수에서 정수 10개를 입력받는다.
* `data + i`는 i번째 배열 요소의 주소이다.

```c
print_odd(data, 10);
print_even(data, 10);
```

* 배열의 시작 주소와 길이를 전달하여 홀수 출력 함수를 먼저 호출하고, 짝수 출력 함수를 나중에 호출한다.

```c
if (array[i] % 2 != 0)
{
    if (count > 0)
        printf(", ");
    printf("%d", array[i]);
    count++;
}
```

* print_odd에서 2로 나눈 나머지가 0이 아닌 값만 출력한다. 음수인 홀수도 올바르게 판별하기 위해 나머지가 1인지 대신 0이 아닌지를 검사한다.
* count를 0으로 초기화하고, 이미 출력한 값이 있을 때만 쉼표를 붙여 숫자 사이를 구분한다.

```c
if (array[i] % 2 == 0)
{
    if (count > 0)
        printf(", ");
    printf("%d", array[i]);
    count++;
}
```

* print_even에서는 2로 나눈 나머지가 0인 값만 출력한다. 0도 짝수에 포함된다.
* 두 함수 모두 배열을 처음부터 검사하므로 각 그룹 안에서는 입력한 순서가 유지된다.

# 도전과제 2

## 문제

10진수 정수 하나를 입력받아 2진수로 변환하여 출력한다.

## 소스코드 설명

[전체 소스코드](challenge_02.c)

```c
void print_binary(unsigned int number);
```

* 0 이상의 정수를 받아 2진수의 각 자리를 출력하는 함수를 선언한다.

```c
int number;
unsigned int magnitude;

printf("10진수 정수 입력: ");
if (scanf("%d", &number) != 1)
    return 1;
```

* 입력받은 정수는 number에 저장하고, 2진수로 변환할 크기는 부호 없는 정수 magnitude에 저장한다.

```c
if (number < 0)
{
    printf("-");
    magnitude = 0u - (unsigned int)number;
}
else
    magnitude = (unsigned int)number;
```

* 음수가 입력되면 먼저 마이너스 기호를 출력하고 절댓값에 해당하는 크기를 구한다. 양수와 0은 그대로 사용한다.
* unsigned int 연산을 사용하면 int형 최솟값도 부호 있는 정수의 범위를 넘는 `-number` 연산 없이 처리할 수 있다.
* 음수는 메모리의 2의 보수 비트열이 아니라 `-1100`처럼 부호와 크기로 표시한다.

```c
void print_binary(unsigned int number)
{
    if (number >= 2)
        print_binary(number / 2);

    printf("%u", number % 2);
}
```

* 정수를 2로 나눈 나머지는 2진수의 가장 낮은 자리이다.
* 몫을 먼저 재귀 호출로 처리한 뒤 나머지를 출력하면 높은 자리부터 출력할 수 있다.
* 예를 들어 12는 12 → 6 → 3 → 1 순서로 호출되고, 돌아오면서 1, 1, 0, 0을 출력하므로 결과는 1100이다.
* 0을 입력하면 재귀 호출 없이 나머지 0을 한 번 출력한다.

```c
print_binary(magnitude);
printf("\n");
```

* 함수를 호출하여 2진수 전체를 출력하고 줄을 바꾼다.

# 도전과제 3

## 문제

정수 10개를 입력받는다. 홀수이면 배열의 앞에서부터, 짝수이면 뒤에서부터 채워 넣고 완성된 배열을 출력한다.

## 소스코드 설명

[전체 소스코드](challenge_03.c)

```c
int data[10];
int i, number;
int front = 0, back = 9;
```

* 정수 10개를 저장할 배열을 선언한다.
* front는 다음 홀수를 저장할 위치이고, back은 다음 짝수를 저장할 위치이다.
* 배열의 첫 인덱스는 0이고 마지막 인덱스는 9이므로 각각 해당 값으로 초기화한다.

```c
if (number % 2 != 0)
{
    data[front] = number;
    front++;
}
else
{
    data[back] = number;
    back--;
}
```

* 입력받은 값이 홀수이면 앞쪽 빈칸에 저장하고 front를 증가시킨다.
* 짝수이면 뒤쪽 빈칸에 저장하고 back을 감소시킨다.
* 입력 한 번마다 빈칸을 하나씩 채우므로 10번 입력하면 모든 요소가 채워진다.
* 홀수는 입력 순서대로, 짝수는 입력 순서의 역순으로 배열에 배치된다.

|입력 순서|입력값|저장 위치|
|------|---:|---|
|1|1|data[0]|
|2|2|data[9]|
|3|3|data[1]|
|4|4|data[8]|
|5|5|data[2]|
|6|6|data[7]|
|7|7|data[3]|
|8|8|data[6]|
|9|9|data[4]|
|10|10|data[5]|

따라서 1부터 10까지 입력하면 배열에 1, 3, 5, 7, 9, 10, 8, 6, 4, 2가 저장된다.

```c
printf("배열 요소의 출력 :");
for (i = 0; i < 10; i++)
    printf(" %d", data[i]);
printf("\n");
```

* 배열을 첫 번째 요소부터 차례로 출력한다.
